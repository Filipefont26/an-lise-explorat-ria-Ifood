Análise de Dados de Marketing do iFood (Python + Pandas)

Este projeto tem como objetivo analisar dados de campanhas de marketing para entender o comportamento dos clientes e identificar oportunidades de melhoria nas estratégias.

Utilizando um dataset inspirado em cenários reais do iFood, a análise busca responder perguntas importantes sobre performance de campanhas, perfil dos clientes e eficiência das ações de marketing.

🎯 Objetivo

Explorar os dados de marketing para:

Entender o perfil dos clientes
Avaliar a efetividade das campanhas
Identificar padrões de consumo
Gerar insights para otimização de estratégias
🛠️ Tecnologias Utilizadas
Python
Pandas
Jupyter Notebook / VS Code

A biblioteca Pandas é amplamente utilizada para manipulação e análise de dados em formato tabular, sendo uma das principais ferramentas no ecossistema de dados em Python

📊 Etapas da Análise
🔍 Exploração Inicial (EDA)
Visualização geral do dataset
Identificação de tipos de dados
Análise de distribuição das variáveis
🧹 Tratamento de Dados
Tratamento de valores nulos
Ajuste de inconsistências
Conversão de tipos de dados
📈 Análise de Comportamento
Perfil dos clientes (idade, renda, etc.)
Padrões de compra
Relação entre campanhas e conversões
📣 Avaliação de Campanhas
Desempenho por tipo de campanha
Taxa de aceitação
Impacto nas vendas
📊 Principais Insights
Nem todos os clientes respondem da mesma forma às campanhas
Determinados perfis apresentam maior propensão de compra
Algumas campanhas têm baixo retorno, indicando oportunidade de otimização
Dados bem analisados permitem direcionar melhor os investimentos
💡 Problema Resolvido

Antes:

Dados dispersos e pouco explorados
Falta de clareza sobre efetividade das campanhas

Depois:

Visão estruturada do comportamento dos clientes
Identificação de padrões e oportunidades
Base para decisões mais estratégicas
🚀 Diferencial do Projeto

Este projeto se destaca por:

Aplicar análise exploratória em um contexto de marketing real
Transformar dados brutos em insights acionáveis
Utilizar Python para substituir análises limitadas em Excel
